# Marsad v0.1.1

Bug fixes only. No interface change, so the patch digit is the honest one. Both
fixes are worst on exactly the clusters Marsad is for.

## Fixed

**A namespace with no policies rendered as a column of dots.** Dagre ranks nodes
by their edges, so every node no edge touches landed in rank 0 and came back as
a single column with an x-span of zero. That is not an edge case: openness is
drawn on the card rather than as edges to a hub, so a namespace whose workloads
no policy selects has no edges at all — which makes the commonest thing in any
real cluster the thing that rendered worst. The camera could only frame such a
namespace by zooming out until every card was a bare dot. Those namespaces lay
out as a grid now, per namespace, so the group boxes stay rectangular and
disjoint. Measured on painted pixels, 40 workloads covered 148x886 before and
1230x702 after.

**The camera fought the user.** It refit on every message from the stream, and
the stream sends a fresh graph on any cluster change — a Job finishing, a
Deployment scaling, a ReplicaSet being collected. On a busy cluster a pan or
zoom was discarded seconds after it was made, and the view appeared to move on
its own for no reason the user could see. Once the camera has been aimed, the
view is theirs: only asking to see something different reframes it — a level
switch, a namespace scope, a posture filter.

**Panning is detected on the window rather than the stage.** A pan very often
ends with the pointer off the canvas, over the rail or outside the document, and
listening on the stage alone missed exactly the drags that travelled furthest.

**Fitting no longer discards its own padding** when one axis has no span. Each
axis is padded independently: a single row or column is a real shape, not a
degenerate case to bail out of.

## Also

The README now shows the dashboard, which a tool whose whole point is what it
renders probably should have done from the start.

## Upgrading

```sh
helm upgrade marsad oci://ghcr.io/fathiq/charts/marsad --namespace marsad
```

Nothing to change in your values.
